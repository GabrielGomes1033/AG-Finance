# AG Finance - Dashboard da Bolsa de Valores Global

💹 **AG Finance** é um dashboard interativo em tempo real que exibe informações sobre o mercado financeiro global, incluindo ações, criptomoedas e índices importantes como IBOVESPA, S&P 500 e NASDAQ. Este projeto é voltado **apenas para fins de estudo** e aprendizado.

## 🔹 Funcionalidades

- Barra de ticker com cotações em tempo real
- Visualização de ativos: IBOV, Dólar, S&P 500, NASDAQ
- Cards com informações resumidas do mercado
- Gráficos interativos (TradingView)
- Tabela de ativos com preço, variação e volume
- Navegação em sidebar com acesso a Notícias, Carteira e Configurações

## 💻 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- TradingView para gráficos em tempo real
- Fontes Google Fonts (Inter)
